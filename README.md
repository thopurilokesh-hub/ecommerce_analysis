# 🛒 E-Commerce Data Analysis using Pandas

## 📌 Project Overview
This project performs **exploratory data analysis (EDA)** on an e-commerce dataset using **Python, Pandas, and Matplotlib**.  
The goal is to extract **business insights** such as sales trends, best-selling products, customer behavior, and category-wise revenue.

This is a **resume-worthy, real-world data analysis project**.

---

## 🎯 Objectives
- Analyze e-commerce sales data
- Identify monthly revenue trends
- Find best-selling products
- Analyze category-wise revenue
- Identify high-value and repeat customers
- Visualize insights using charts

---

## 🛠️ Technologies Used
- Python 3
- Pandas
- Matplotlib
- CSV file handling

---

## 📊 Dataset Description
The dataset contains order-level e-commerce information.

| Column Name | Description |
|------------|------------|
| OrderID | Unique order ID |
| OrderDate | Date of order |
| CustomerID | Unique customer ID |
| Product | Product name |
| Category | Product category |
| Quantity | Units purchased |
| Price | Price per unit |

---

## ⚙️ Features Implemented

### 🔹 Data Processing
- Load CSV data using Pandas
- Convert dates to datetime format
- Create new feature: `TotalSales`

### 🔹 Analysis
- Total revenue calculation
- Monthly sales trend analysis
- Category-wise revenue analysis
